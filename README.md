# Invoker Skills — мод для Fabric 1.21.4

Скилы в стиле Инвокера из Dota 2: три клавиши **Z, X, Y** = три "орба".
Порядок нажатий не важен, повторять клавиши можно. Как только нажаты
любые 3 клавиши подряд (в течение ~3 секунд), заклинание кастуется
**автоматически** — отдельной кнопки "invoke" нажимать не нужно.

10 заклинаний (Z=0, X=1, Y=2, комбинация считается по количеству,
не по порядку — как quas/wex/exort в Dota):

| Комбо | Заклинание |
|---|---|
| ZZZ | Ледяная волна — урон + замедление вокруг тебя |
| ZZX | Морозный шаг — невидимость + скорость |
| ZZY | Ледяная стена — временная стена изо льда |
| ZXX | ЭМИ — снимает баффы с врагов рядом |
| ZXY | Торнадо — подбрасывает врагов в воздух |
| ZYY | Ускорение — баф скорости/добычи/прыжка на себя |
| XXX | Дух кузни — призывает союзного голема |
| XXY | Метеор — огненный взрыв в точке прицела |
| XYY | Удар молнии — молния в точку прицела |
| YYY | Оглушающий взрыв — отталкивает и слепит врагов вокруг |

Это **исходный код**, а не готовый .jar — сам код мода занимает мало
места, а вот всё остальное (Minecraft, маппинги, Fabric API) весит
гигабайты и должно скачиваться Gradle'ом на твоей машине с интернетом.
Поэтому в архиве только `src/` + резервные gradle-файлы, а собирать
jar будешь ты, по инструкции ниже — это буквально то же самое, что
"переделать zip с гитхаба в jar".

---

## Что тебе понадобится

1. **JDK 21** (Java Development Kit). Скачать: https://adoptium.net/ (выбери версию 21).
   Проверить, что стоит: в терминале `java -version` — должно быть `21.x`.
2. **Интернет** — при первой сборке Gradle скачает Minecraft, Fabric Loader,
   Fabric API и маппинги (~500 МБ – 1 ГБ). Это нормально, происходит один раз.
3. Желательно **IntelliJ IDEA Community Edition** (бесплатная) — сильно
   упрощает жизнь, но можно обойтись только терминалом.

---

## Шаг 1. Возьми официальный каркас проекта (самый надёжный способ)

Версии Minecraft/Fabric API/маппингов постоянно обновляются, поэтому
безопаснее не полагаться на числа, зашитые в мой архив, а взять свежий
официальный шаблон:

1. Открой https://github.com/FabricMC/fabric-example-mod
2. Нажми зелёную кнопку **Code → Download ZIP**
3. Распакуй этот zip в отдельную папку, например `fabric-template/`

Это и есть тот самый "зип с гитхаба", про который ты спрашивал — в нём
уже лежат правильные `build.gradle`, `gradle.properties`, `gradlew`,
`gradlew.bat` под актуальную версию Fabric.

## Шаг 2. Открой файл `gradle.properties` в шаблоне

Поменяй в нём (или проверь, что уже стоит) версию Minecraft на `1.21.4`.
Актуальные номера `yarn_mappings`, `loader_version`, `fabric_version`
для 1.21.4 всегда можно взять на официальном генераторе:
https://fabricmc.net/develop/template/ (выбери там 1.21.4 — сайт сам
покажет актуальные версии, их можно скопировать в `gradle.properties`).

## Шаг 3. Скопируй мои файлы в шаблон

Из моего архива `invoker-skills-mod.zip` перенеси **с заменой**:

```
invoker-skills-mod/src/main/java/com/invokerskills/...   →  fabric-template/src/main/java/com/invokerskills/...
invoker-skills-mod/src/main/resources/fabric.mod.json    →  fabric-template/src/main/resources/fabric.mod.json
invoker-skills-mod/src/main/resources/assets/invokerskills/...  →  fabric-template/src/main/resources/assets/invokerskills/...
```

Удали из `fabric-template/src/...` старые примерные файлы шаблона
(`ExampleMod.java`, `ExampleModClient.java`, старый `fabric.mod.json`,
если только не хочешь оставить их для справки — тогда просто не
регистрируй их entrypoint'ы в `fabric.mod.json`).

Если лень возиться с переносом — можно наоборот: скопировать
`build.gradle`, `gradle.properties`, `settings.gradle`, `gradlew`,
`gradlew.bat`, папку `gradle/` из шаблона **в мой архив**, поверх моих
резервных файлов. Итог одинаковый.

## Шаг 4. Собери jar

Открой терминал в папке проекта (там, где лежит `gradlew`) и выполни:

**Windows (PowerShell / cmd):**
```
gradlew.bat build
```

**macOS / Linux:**
```
chmod +x gradlew
./gradlew build
```

Первая сборка займёт несколько минут (качается интернет). Если всё
прошло без ошибок, готовый файл появится тут:

```
build/libs/invoker-skills-1.0.0.jar
```

Файл `build/libs/invoker-skills-1.0.0-sources.jar` — это НЕ то, что
нужно устанавливать в игру, его можно игнорировать.

## Шаг 5. Установи мод в игру

1. Установи **Fabric Loader** для Minecraft 1.21.4 (через официальный
   установщик https://fabricmc.net/use/installer/).
2. Скачай **Fabric API** для 1.21.4 (с Modrinth или CurseForge) —
   без него мой мод не запустится, я использую его сетевые/tick-события.
3. Найди папку `.minecraft/mods` (в лаунчере Minecraft она открывается
   через "Open mods folder" в профиле Fabric).
4. Положи туда **оба** файла:
   - `fabric-api-*.jar` (скачанный)
   - `invoker-skills-1.0.0.jar` (твой, собранный на шаге 4)
5. Запусти Minecraft с профилем Fabric 1.21.4.

## Шаг 6. Проверка

Заходишь в мир и жмёшь любые 3 клавиши из Z/X/Y (в любом порядке,
можно с повтором) — в чате/action bar появится название заклинания и
эффект сработает. Например ZZZ — ледяная волна вокруг тебя.

## Если Gradle ругается на сборке

- **"Unsupported class file version" / ошибки Java** — проверь, что
  `java -version` показывает именно 21, а не 8/11/17.
- **"Could not resolve..." / ошибки скачивания** — проверь интернет,
  попробуй `./gradlew build --refresh-dependencies`.
- **permission denied: ./gradlew** (Linux/macOS) — выполни
  `chmod +x gradlew` и повтори.
- **Ошибки компиляции про несуществующие методы** (типа "cannot find
  symbol") — значит между версией Minecraft в `gradle.properties` и
  API, который я использовал, есть небольшие расхождения (Mojang
  иногда переименовывает методы). Открой файл с ошибкой в IntelliJ
  IDEA — она подскажет правильное имя метода через автодополнение
  (обычно переименование, а не удаление функциональности).

## Важно

Это не точная копия персонажа/заклинаний Dota 2 — механика "три
клавиши → комбинация → способность" здесь реализована своими
эффектами на ванильных возможностях Minecraft (частицы, статус-эффекты,
призыв мобов, урон), только вдохновлена идеей Инвокера.
